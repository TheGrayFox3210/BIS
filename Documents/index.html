BIS Overview

BIS ソリューション概要

BIS は複数プロジェクトから構成されるソリューションであり、共通ルール、ソリューション構造、BIS 固有の実装方針を段階的に組み合わせて開発されます。

この資料は、BIS におけるルールや設計方針がどのように整理されているかを、人間が確認しやすい形でまとめたものです。

Version 2 Status: draft Encoding: UTF-8

記述の構成

BIS の記述は、上位ほど独立性が高く、下位ほど BIS 固有の文脈を含む 3 段階で整理されています。

  • L1 は、対話姿勢や情報の扱い方など、利用者との基本的な運用方針を定義します。
  • L2 は、BIS に限定しない C# / Unity の共通規約を定義します。
  • L3 は、BIS ソリューション固有の構造、用語、命名、通信方針を定義します。
